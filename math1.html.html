關卡三：數學思想時光機

3. 「證明觀念」的歷史演進時間軸 📜

從「實務經驗測量」到「幾何推理」，再到「公理化演繹」——人類如何理解「數學證明」？

1

古代實務經驗與測量數組 🏕️

約西元前 2000 - 前 1000 年

古埃及結繩者與古巴比倫人早已發現 $(3,4,5)$ 或 $(5,12,13)$ 等特定邊長組合可用於直角測量與工程。此階段停留在經驗紀錄與特例計算，尚未形成一般性證明。

2

中國勾股傳統與《周髀算經》 ⛩️

漢代及以前文獻

《周髀算經》記載了「勾廣三，股修四，徑隅五」與趙爽弦圖。這標誌著從單純計算走向視覺幾何圖形輔助說明的重要跨越。

3

劉徽《九章算術注》：出入相補 🧩

西元 3 世紀（魏晉）

劉徽運用「出入相補」（割補拼接）原理，將圖形切割拼合轉化為面積證明。這種方法強調面積守恆與幾何構型的一般性推理。

4

歐幾里得《幾何原本》：公理化演繹 🏛️

約西元前 300 年

《幾何原本》卷一命題 47 代表人類思想史重大轉折：從具體問題解法轉向「定義 ➔ 公設 ➔ 命題 ➔ 演繹證明」的嚴密體系，建立科學理性基石。

東方計算與割補體系 (Dissection)

以《九章算術》與劉徽注為代表，聚焦問題求解與幾何切割，具備強大實用性與直觀視覺性。

古希臘公理演繹體系 (Deductive)

以《幾何原本》為代表，強調嚴密的邏輯鏈條，建立自洽的幾何體系。

關卡四：拉開角度的大突破

4. 自由調整邊長與角度 ➔ 餘弦定理與不等式 🎈

調整兩邊長 $a, b$ 與頂角 $C$，觀察畢氏定理如何自然推廣為餘弦定理與三角形不等式！

邊長 $a$： 3
邊長 $b$： 4
頂角 $\angle C$ 大小： 90°
10° (銳角) 170° (鈍角)
當前三角形狀態 直角三角形 ($C = 90^\circ$)
兩邊平方和 $a^2 + b^2$ 25
對邊平方 $c^2$ 25
平方大小關係：
$c^2 = a^2 + b^2$

📐 一般三角形：餘弦定理 (Law of Cosines)

$$c^2 = a^2 + b^2 - 2ab \cos(C)$$

當 $C=90^\circ$ 時，$\cos 90^\circ = 0$，修正項 $-2ab\cos C$ 歸零，立刻還原為畢氏定理！畢氏定理就是餘弦定理在直角時的完美臨界點！

🌟 終極延伸：三角形不等式

當 $C \to 0^\circ$ 或 $C \to 180^\circ$ 時，三角形退化為線段，邊長 $c$ 永遠受限於：

$$|a - b| < c < a + b$$
